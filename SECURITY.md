# Politique de sécurité

## Versions supportées

| Version | Supportée |
| --- | --- |
| `main` / dernière version | :white_check_mark: |
| Anciennes versions | :x: |

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique.**

Utilisez le signalement privé de vulnérabilité de GitHub : onglet [Security](https://github.com/ymauray/scrubx/security), puis **Report a vulnerability**.

Décrivez le problème, les étapes pour le reproduire et son impact potentiel. Le signalement sera examiné dans les meilleurs délais, et un correctif sera publié avant toute divulgation publique.
